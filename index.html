第一次如何获得访问令牌？
  1. 打开 创建专用令牌，登录你的 GitHub。
  2. Repository access 选择 Only select repositories，只选 proxy-scout-cloud。
  3. 权限保留 Actions: Read and write、Contents: Read-only。
  4. 点 Generate token，复制令牌粘贴到下面。

未勾选时仅保留在当前会话。令牌只发送给 GitHub，用于读取你的结果和发起测速。
